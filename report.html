摘要

随着文生图模型从「生成正确」走向「生成真实与美」，模型能力的评价标准正在发生变化。单纯考察指令遵循已不足以描述一个模型在真实创作场景中的表现，隐性审美、质感还原与文化理解正在成为新的能力分水岭。本报告以 Midjourney V8.2、Seedream 5.0 Pro、Kling Image 3.0 三个主流模型为对象，通过 82 道跨场景题目，从风景美学、叙事感女性人像美学两个正式维度对当前文生图模型的能力边界进行系统性评测，通用能力作为先导研究用于验证评测方法。

本报告的核心方法论，是「先导研究—正式研究」两阶段评测设计。通用能力部分作为先导研究，采用单层 1—5 分制进行探索性评分，用于验证评分维度、识别提示词约束等问题，并为正式研究提供修正依据。风景美学与叙事感女性人像美学作为正式研究，均采用「显性指令符合度 / 美学质量」双层评分逻辑：风景评测中，准确度与美学质量在同一组维度上呈互补关系，提示词明确要求某一视觉要素时进入准确度评分，未明确要求时进入美学质量评分；人像评测中，准确度与美学质量分为两套独立维度，准确度维度仅在提示词明确涉及对应要素时激活，美学质量维度则独立评分。两者共同构成正式研究的双层评分框架。

本报告根据不同评测阶段与维度类型，采用三套评分口径：通用能力作为先导研究，数据仅作方法论验证参考，其指令遵循度、物理真实感、美学质量、风格一致性与文化合理性均采用 1—5 分制评分；风景与人像的准确度维度采用 1/0 分制，结果以准确率（%）表示；风景与人像的美学质量维度采用 1—5 分制，5 分为满分，3 分为及格线，2 分及以下为明显缺陷。

评测结果显示，三个模型的能力差异呈结构性分化。Midjourney V8.2 的核心特征是美学表现突出、准确执行偏弱：画面氛围和摄影质感最强，尤其在人像方面色彩、光影质量、服装/造型美学上表现突出，然而其通用能力评测中文化合理性严重偏低，对中国传统节日与东方艺术风格的理解仍停留在符号层面。Seedream 5.0 Pro 是当前三个模型中最接近「技术正确」的一个，准确执行能力最强，美学表现中上，但尚未形成显著的美学风格优势，尤其人像服装造型美感偏弱。Kling Image 3.0 在指令遵循和文化合理性上表现尚可，但在真实质感维度上出现系统性落后：人像美学皮肤细节与身体结构自然度、服装与造型美学维度评分，风景美学色彩、细节自然度得分显著低于其他模型，这显示其尚未跨越从「画得对」到「画得真」的能力门槛。

报告进一步识别出当前文生图模型的短板：一是景别理解不准，人像景别准确度在三个模型中最高仅 62.1%；二是逆光、侧光、侧逆光等光位常被模型混淆，生成结果与提示词要求不一致，自然光还原度在三模型中集中于 66.7%—70.0%；三是东方风格理解存在分化，Midjourney V8.2 将春节生成为符号堆砌，Kling Image 3.0 将水墨画泛化为工笔彩绘，均未触及东方美学核心，Seedream 5.0 Pro 则相对稳定。

本报告对风景专项的低分案例进行了逐题归因，并对人像专项的低分问题进行了归纳总结，给出可落地的改进方向。本报告不仅提供模型对比结果，更形成了一套理解文生图模型能力边界的认知框架。报告结论基于当前模型版本与评测方法，是一次阶段性观察。

一、评测背景与目标

1.1 评测背景

文生图模型在过去两年经历了快速迭代。随着生成质量的整体提升，模型之间的竞争正在发生转移。分辨率、基础语义正确性不再是主要瓶颈，真正拉开差距的是：生成结果是否具备真实摄影质感、是否具有可识别的美学调性、是否能在特定文化与风格语境下准确表达。与此同时，国内模型与海外模型在中文理解、东方文化呈现和真实质感还原上，开始出现明显的能力分化。

这一阶段，评测不能再以「对错」为唯一标准。评测者需要在「对不对」与「好不好」之间建立新的分析框架，才能更准确地刻画模型能力边界。

1.2 评测目标

本次评测试图回答四组问题。

第一组：显性指令执行能力。当提示词明确指定构图方式、光线类型、景别、人物特征、风格约束时，模型是否能够忠实执行，而非依赖默认生成策略？

第二组：美学质量呈现能力。模型生成结果是否在构图、光影、影调、色彩、透视等方面达到专业摄影美学水准。风景中，该能力在提示词未明确要求时评价；人像中，该能力独立评价，不依赖提示词是否明确要求。

第三组：真实质感还原能力。皮肤纹理、服装材质、环境细节、景深虚化等「真实感」维度，是否已成为模型之间差异最大的分水岭？

第四组：文化与风格理解能力。海外模型与国内模型在中国传统节日、水墨画、古典建筑等东方语境下的表现差异有多大？模型失败的原因是数据缺失、风格理解偏差，还是文化语义的空白？

这四组问题是本报告的探究方向，不是评分维度。评分维度将在各专项中另行定义。

二、评测设计

2.1 两阶段设计：先导研究—正式研究

本次评测采用「先导研究—正式研究」两阶段设计。

先导研究以通用能力为主要内容，目的是验证评分维度是否可用、题目难度分层是否合理、跨模型对比是否可行。通过先导研究，评测者识别出写实风格约束缺失、光效词汇歧义等问题，并据此对正式研究进行修正。景别标准则在正式研究人像专项设计过程中进一步细化。

正式研究包含风景美学与叙事感女性人像美学两个专项。正式研究在先导研究的基础上，采用更成熟的「显性指令符合度 / 美学质量」双层评分逻辑，维度划分更细，评分标准更明确，样本量更充分。

这一设计使评测方法本身具有演进性，而非一次性成型的静态方案。

2.2 评分逻辑

正式研究部分采用「显性指令符合度 / 美学质量」双层评分逻辑。

显性指令符合度回答：模型是否精确执行了提示词中明确写出的要求。该层只在提示词明确涉及某一要素时激活，采用 1/0 分制，结果以准确率表示。

美学质量回答：模型生成结果在视觉美学上是否达到专业水准。该层采用 1—5 分制评分，5 分为满分，3 分为及格线，2 分及以下为明显缺陷。

风景与人像在具体结构上存在差异。

风景评测：准确度与美学质量在同一组维度上呈互补关系。提示词明确要求某一视觉要素时，该维度进入准确度评分（1/0）；未明确要求时，进入美学质量评分（1—5）。例如，提示词写「三分法构图」时，构图维度评准确度；未写时，构图维度评美学质量。

人像评测：准确度与美学质量分为两套独立维度。准确度维度仅在提示词明确涉及对应要素时激活，美学质量维度独立评分，不依赖准确度是否激活。例如，无论提示词是否写「皮肤真实」，皮肤细节维度都会评美学质量。

风景与人像采用不同评分结构，不是设计偏好，而是由两类题材的评分对象属性决定的。风景维度大多可以客观判断「对不对」，因此适合在同一组维度上互补评分；人像的很多美学维度无法用对错衡量，只能评「好不好」，因此必须将准确度与美学质量拆成两套独立维度。

2.6 正式研究提示词设计对先导研究的继承

正式研究的提示词设计，直接受到先导研究阶段发现的问题影响。先导研究暴露出的关键问题，在正式研究中得到了修正。

第一，写实风格约束的统一。先导研究阶段发现，部分人物类题目未显式声明「写实」，导致 Midjourney V8.2 在复杂人物场景中生成漫画风格，物理真实感评分失效。因此，正式研究的人像专项提示词统一加入「写实摄影，真实皮肤质感，非动漫」。风景专项未加该约束，原因有二：一是自然风光题材默认即写实方向，发生风格漂移的概率极低；二是风景题库中包含水墨画、日系清新等风格题，统一加写实约束会与风格准确度评测直接冲突。实际评测中，风景题未出现风格漂移，证明该设计成立。

第二，光效词汇的明确化。先导研究阶段发现，模型对「逆光」「侧逆光」等光位理解不稳定，容易混淆。正式研究阶段，人像提示词中对光效的描述更多样和明确，例如「侧逆光从窗外照入」「逆光从窗外照入」，以减少光位理解的歧义。

2.7 评测执行流程

  1. 根据专项维度设计提示词，覆盖目标能力点；
  2. 各模型按统一画幅生成多张，选取最优一张进入评分；
  3. 先评准确度，再评美学质量；
  4. 对低分案例进行归因分析；
  5. 统计均分，绘制对比图表，形成能力画像。

三、先导研究——通用能力评测

本部分评测方法见附录 1-1，完整题目（中英文提示词）见附录 1-2，生成图片、评分及 Bad Case 分析见附录 1-3，均分及可视化见附录 1-4。

3.1 先导研究设计目的

通用能力评测在先导研究中承担三项任务：

第一，验证评分维度是否可用。指令遵循度、物理真实感、美学质量、风格一致性、文化合理性、安全合规性这六个维度，是否能够在不同难度题目上被稳定评分，是否能够反映模型之间的差异。

第二，验证题目难度分层是否合理。L1、L2、L3 三层难度设计，是否能够递进地暴露模型能力边界。

第三，识别正式研究需要修正的问题。这是先导研究最重要的目的。通过低分案例和评分过程中的实际问题，明确正式研究在提示词设计、评分标准、维度结构上需要作出哪些调整。

因此，通用能力部分的结果不作为最终结论，而作为正式研究的方法论输入。

先导研究的核心发现，集中在三个方面。

第一，三模型在基础能力上已经出现分化。Seedream 5.0 Pro 在指令遵循、物理真实感、文化合理性上接近满分，表现最均衡；Kling Image 3.0 指令遵循较高，但物理真实感和美学质量明显偏低；Midjourney V8.2 文化合理性仅为 3.00，风格一致性 3.75，在东方文化和风格理解上出现明显短板。安全合规性方面，三模型都通过。

第二，复杂人物场景下的物理真实感是明显薄弱点。手部精细交互、长文本多元素场景等题目中，模型容易出现主体缺失、皮肤质感不足、衣物细节缺失等问题。

第三，东方风格与文化理解存在分化。在 G-23 春节场景题（春节里，红春联、红灯笼，三代同堂团圆）中，Midjourney V8.2 生成符号堆砌，未体现三代同堂团圆，汉字错乱，对联格式错误。在 G-14 中国水墨画风格题（黑白墨色，写意笔触，坐姿猫，留白构图）中，Kling Image 3.0 生成「墨线勾边 + 彩块填充」，将水墨画泛化为工笔彩绘。

这说明东方风格与文化理解在当前文生图模型中仍不稳定：海外模型容易停留在文化符号表面，国内模型也可能发生风格泛化。Seedream 5.0 Pro 在同类题目上表现相对最稳。

3.4 对正式研究的修正产出

先导研究最重要的价值，是直接指导了正式研究的设计修正。两个关键修正如前文 2.6 所述：

  1. 写实风格约束的统一：人像专项统一加入「写实摄影，真实皮肤质感，非动漫」，避免复杂人物场景发生动漫化漂移；
  2. 光效词汇的明确化：人像提示词中对光效描述更明确，减少逆光、侧逆光等光位混淆；

此外，先导研究还提示正式研究需要在物理真实感、真实质感等维度上给予更大权重。这直接影响了人像专项的维度设计，使皮肤细节、服装造型、环境细节等真实质感维度成为独立评分项。

四、正式研究一——风景美学专项评测

本部分评测方法见附录 2-1，完整题目（中、英文提示词）见附录 2-2，生成图片、评分及 Bad Case 分析见附录 2-3，均分及可视化见附录 2-4。

4.1 维度设计

风景美学专项共设置 9 个评分维度，其中 7 个为核心维度，2 个为条件激活维度。

核心维度（7 个）：构图与视觉平衡、层次感与空间深度、光线、影调、色彩、细节自然度、景深。这 7 个维度始终参与评分，但评分性质由提示词决定：提示词明确要求某一视觉要素时，该维度进入准确度评分（1/0）；提示词未明确要求时，该维度进入美学质量评分（1—5）。

条件激活维度（2 个）：专业风格符合度、文化合理性。仅当提示词明确指定风格或涉及人文元素时，这两个维度才进入准确度评分；若提示词未涉及，则记为 N/A，不参与任何均分。

因此，风景评测的准确度与美学质量在 7 个核心维度上呈互补关系：同一维度要么评准确度，要么评美学质量，不会同时评分。专业风格符合度与文化合理性则只评准确度，不评美学质量。

现象：人物位于画面中间，未按要求位于右三分之一处；整体色相偏暖色，未呈现蓝调风格。

归因：该案例同时暴露了 Midjourney V8.2 的两个问题。第一，构图指令未被执行。提示词明确要求「背影位于画面右三分之一处」，但生成结果将人物置于画面中部，说明模型在处理明确空间位置指令时仍不稳定。第二，风格语义理解出现偏差。提示词明确要求「蓝调风格」，模型却生成了暖色画面，说明其将「蓝调」泛化为普通风光色调，而非严格按蓝色主调执行。

归因：该题在准确度上并未失分，说明 Seedream 5.0 Pro 正确执行了「前景虚化、焦点落在远处一棵树」的指令。问题出在美学质量中的构图维度。模型在自由构图时，未将主体放在合理的视觉位置，导致树木被裁切、画面失重。这属于构图美学判断能力不足，而非指令理解错误。对于未明确指定构图方式的题目，模型倾向于生成「技术上正确但审美上平庸或失衡」的结果。

启示：Seedream 5.0 Pro 在风景准确度上表现最稳，但自由构图时的审美稳定性仍有提升空间。这也说明准确度高不等于美学质量高，两者需要分开评价。

建议：引入构图美学先验，避免主体贴边或过度裁切；训练数据中增加主体位置、留白与视觉平衡的优质样本。

题目：高山草甸全景，前景野花、中景溪流、远景雪山全部清晰，小光圈、大广角风光摄影，细节丰富

现象：影调过渡差，草原与雪山拼接感强；野花呈动漫感，出现色块；黄色饱和度和明度偏高。

归因：Kling Image 3.0 在该题中暴露了多个维度的能力短板。细节自然度准确度为 0，雪山纹理缺失，野花被过度简化为色块，缺乏真实植物纹理；影调上，前景、中景、远景的明暗关系不统一，出现明显的「拼接感」；色彩上，黄色饱和度过高，不符合真实风光摄影的克制感。这三个问题共同指向一点：Kling Image 3.0 在多元素自然风光合成时，空间、光影和纹理的真实感控制能力仍较弱。

启示：Kling Image 3.0 的基础指令遵循尚可，但一旦进入高细节、多层次的真实风光场景，其生成质量会明显下降。真实质感是 Kling Image 3.0 与 Midjourney V8.2、Seedream 5.0 Pro 之间的主要差距。

建议：增加高分辨率真实风光摄影训练样本，尤其强化草地、雪山、野花等自然纹理；在色彩训练中约束饱和度范围，避免过度鲜艳；同时提升多尺度场景的影调统一性。

4.5 小结

Midjourney V8.2 的核心特征是美学质量突出，但风格执行不稳。影调、景深、层次感/空间深度、构图/视觉平衡等维度均表现优异，自然风光画面在摄影质感上最强。但专业风格契合度严重偏低，说明其在需要遵循明确风格指令时存在明显能力边界。

Seedream 5.0 Pro 的核心特征是准确度最稳、美学均衡。在风景评测中，Seedream 5.0 Pro 是执行提示词最稳的模型，且在美学质量上无明显短板。其自然风光画面在色彩、细节、光线上均有较好表现，整体能力最均衡。

Kling Image 3.0 的核心特征是基础准确度尚可，但真实纹理与色彩影调落后。构图、色彩、景深、文化合理性等维度准确度不低，但细节自然度严重偏低。美学质量中色彩、影调明显偏弱，画面在真实风光质感和色彩和谐度上仍有较大提升空间。

风景准确度方面，各个模型达成效果较好，专业风格契合度、细节自然度、光线和影调是拉开模型表现力的四个维度。在美学质量层面，细节自然度、色彩和影调是三个区分度最明显的维度。

5.5 小结

整体而言，景别和自然光还原度是最稳定、最明确的共同短板。景别方面，三个模型均处于较低水平，为 48.3%~62.1%。「半身/全身/大景」的边界容易被模型混淆，导致取景范围与提示词要求不一致，其中，Midjourney V8.2 的问题最为严重。光线方面是三模型共同的第二短板。自然光还原度的准确性方面，Midjourney V8.2 为 66.7%，Seedream 5.0 Pro 为 70.0%，Kling Image 3.0 为 66.7%，三模型均未突破 70%。主要问题是模型未能按照提示词指令执行，逆光、侧光、侧逆光等光位容易混淆。光效表述明确化后问题依旧，说明短板源于模型光位理解能力，而非提示词表述。但 Midjourney V8.2 的光影质量远高于 Kling Image 3.0，主要体现在面部生成复杂光影，塑造有「氛围感」的画面效果，而这是 Kling Image 3.0 的明显短板。

Midjourney V8.2 的核心特征是美学质量突出，但准确度执行不稳。美学质量层面，Midjourney V8.2 在色彩、服装、层次感、人物融合、环境细节等维度上均明显领先，画面氛围和摄影质感最强。但准确度层面，景别准确率仅 48.3%，超过一半的题目未按要求生成，视角/神态、自然光还原度、构图/机位也均为三模型最低。Midjourney V8.2 的能力画像呈明显的「美感强、执行弱」特征。

Seedream 5.0 Pro 的核心特征是准确度强、美学质量中上，但复杂姿态和服装造型是薄弱点。准确度层面，Seedream 5.0 Pro 在所有七个维度上均没有明显短板，是三模型中执行最稳定的模型。美学质量层面，影调和皮肤细节表现最好，但服装造型美感偏弱，款式不出彩、褶皱生硬、材质垂坠感一般。此外，在坐姿、蹲姿等复杂姿态下，Seedream 5.0 Pro 出现四肢结构错误，说明其身体结构控制仍不够稳定。

Kling Image 3.0 的核心特征是基础能力尚可，但真实质感系统性落后。准确度层面，Kling Image 3.0 处于中间位置，没有特别突出的强项。美学质量层面，12 个维度中有 11 个为三模型最低，皮肤细节、服装造型、动态快门均低于及格线。Kling Image 3.0 的问题不是某一个维度的偶发失误，而是皮肤、服装、环境、动态等多个真实质感相关维度整体偏弱，属于底层生成能力的系统性不足。

六、总结

6.1 三模型能力画像

综合通用能力、风景美学、叙事感女性人像美学三个专项的结果，三个模型的能力差异呈现稳定且一致的结构性分化。

Midjourney V8.2 的核心特征是美学表现突出、准确执行偏弱。Midjourney V8.2 在美学质量上优势明显。风景中，光线、景深均达到 5.00，构图/视觉平衡、层次感/空间深度、影调同样处于领先水平；人像中，色彩、光影质量、服装造型、人物与环境融合、环境细节自然度、动态与快门感均高于另外两个模型，画面氛围和摄影质感最强。但准确度层面，Midjourney V8.2 的问题较为突出。风景中，专业风格契合度准确率仅为 20.0%；人像中，景别准确率仅为 48.3%。其能力画像呈现明显的「美感强、执行弱」特征：在自由生成时表现优异，但在需要严格遵循提示词指令时，稳定性和准确性明显不足。

Seedream 5.0 Pro 的核心特征是均衡与可靠。在三个专项中，Seedream 5.0 Pro 均未出现明显的能力塌陷。风景准确度中，其所有维度执行均为最优；人像准确度中，其综合表现同样最强。人像美学质量层面，Seedream 5.0 Pro 在影调和皮肤细节上表现突出，但色彩、服装/造型美学、动态与快门感与 Midjourney V8.2 有一定差距。总体来看，Seedream 5.0 Pro 是当前三个模型中最接近「技术正确」的一个，准确执行能力最强，美学表现中上，但尚未形成显著的美学风格优势。

Kling Image 3.0 的核心特征是基础执行尚可、真实质感系统性落后。Kling Image 3.0 在准确度层面并非全面落后。人像准确度处于三模型中间水平，景深/虚化准确率也达到 100.0%。但美学质量层面，Kling Image 3.0 的问题具有明显的系统性。人像美学质量中，12 个维度有 11 个为三模型最低，皮肤细节与身体结构自然度、服装与造型美学、动态与快门感，均为低分。风景美学中，影调、色彩，也显著低于另外两个模型。Kling Image 3.0 的主要问题不在「能不能听懂指令」，而在「听懂之后能不能生成具有真实质感和美学质量的画面」。

6.2 准确度与美学质量的关系

三个专项的结果共同指向一个关键结论：准确度与美学质量是两个相对独立的能力维度，不能互相替代，也不能用一个维度的表现推断另一个维度。

Midjourney V8.2 是最典型的例子。它在美学质量上表现最强，但在准确度上却存在明显短板。风景专业风格契合度准确率仅 20.0%，人像景别准确率仅 48.3%，与其在美学质量上的高分形成明显反差。这说明 Midjourney V8.2 擅长「生成好看的画面」，但当提示词包含明确的构图、风格、景别等指令时，其执行能力并不稳定。

Kling Image 3.0 的情况再次证明两者不可混为一谈。它在指令遵循、文化合理性等准确度维度上并不差，但美学质量中的真实质感维度全面偏低。即使准确执行了场景、构图、光线等指令，生成结果仍可能因皮肤塑料感、服装生硬、环境失真而缺乏真实感。

因此，评测文生图模型时，不能只看总分，也不能只评「好不好」而忽略「对不对」。准确度和美学质量需要分层评价，才能准确刻画模型的能力结构。

6.3 跨专项共性短板

从三个专项的结果看，当前文生图模型存在三个较为稳定的共性短板。

第一，景别理解不准。人像专项中，景别是三个模型准确度最低的维度。半身、全身、大景的边界尤其容易混淆。总体来看，模型对取景范围和空间边界的语义理解仍不够精确，是当前文生图模型最普遍的执行短板。

第二，光位理解与执行不稳。人像专项中，自然光还原度是三模型的共同弱项，评分均未突破 70%。逆光、侧光、侧逆光等光位常被模型混淆，生成结果与提示词要求不一致。风景专项中，光线准确度虽然较高，但在逆光星芒、丁达尔效应等特殊光学现象上仍出现执行失败。模型对光的方向、轮廓光和明暗分界的控制尚未达到稳定水平，这一短板在需要精确光效的人像场景中尤为明显。

第三，东方风格与文化的理解存在分化。风景专业风格契合度中，Midjourney V8.2 也远低于其他模型，在水墨画、日系清新等风格上多次执行失败。Kling Image 3.0 虽然文化合理性较高，但在水墨画风格上出现「墨线勾边 + 彩块填充」的泛化问题。Seedream 5.0 Pro 在东方风格与文化题目上表现相对最稳，说明国内模型在东方语境理解上整体优于海外模型，但仍存在风格泛化的风险。

6.4 美学能力分水岭

风景专项中，细节自然度成为 Kling Image 3.0 与另外两个模型之间的主要分水岭。Kling Image 3.0 雪山纹理、水面波纹、树叶等自然纹理存在明显失真，而 Seedream 5.0 Pro 和 Midjourney V8.2 在该维度上表现远超 Kling Image 3.0。

人像专项中，真实质感维度的分化更加明显。光影质量、皮肤细节与身体结构自然度、服装与造型美学、环境细节自然度、动态/快门感五个维度，是三个模型间差距最大的维度。

这说明，真实质感已经取代基础语义正确性，成为当前文生图模型竞争的核心。模型能否从「画得对」跨越到「画得真」，将决定其在下一阶段竞争中的位置。对于 Kling Image 3.0 而言，皮肤、服装、环境纹理和动态表现的系统性落后，是其当前最需要优先解决的能力缺口。

七、方法论价值、局限与改进方向

7.1 方法论价值

本次评测在方法设计上形成了几个可复用的核心机制。

第一，显性指令符合度与美学质量分离。评测将「是否执行指令」与「生成结果是否具有美学质量」作为两个独立层面评价，避免了传统评测中「没做对」与「做得不好」混为一谈的问题。这一设计使模型的能力结构能够被更准确地识别，尤其避免了因美学质量高而掩盖准确度不足，或因准确度高而忽略美学表现不足的情况。

第二，两阶段设计使评测方法本身具有演进性。通用能力作为先导研究，承担了维度验证和问题识别功能。写实风格约束缺失、光效词汇歧义等问题，在先导研究阶段被发现并在正式研究中修正。这种设计说明评测框架不是一次性成型的静态方案，而是在实践过程中不断修正和完善的结果。

第三，评分锚点与扣分说明提供了可追溯依据。各维度均配有明确的评分标准和分数段表现描述，低分案例配有具体扣分说明。这使得评分过程具有一定可复现性，也便于后续对争议题目进行复核。

第四，归因分析区分了不同来源的问题。低分案例被区分为提示词设计缺陷、模型能力短板、训练数据偏差等类型，并给出了对应的改进方向。这种归因方式比单纯的分数对比更能为模型优化提供可落地的参考。

7.2 局限性

本次评测存在以下局限，需要在解读结论时予以考虑。

第一，样本量有限。本次评测共 82 题，虽已覆盖主要能力方向，但部分维度激活样本偏少。尤其物理真实感、动态与快门感等维度，在少数题目上得分波动可能影响均分稳定性。后续应扩充题库，重点增加高区分度维度的样本量。题目设置仍有待加强，部分题目未能有效区分模型能力，尤其风景专项的准确度维度存在天花板效应，区分度不足，属于本次设计短板。人像测评侧重单人，缺少多人互动评测维度。

第二，评分主观性。美学质量评分由单人完成，虽然依据评分锚点，但不可避免存在主观性。后续应引入多人盲评，并计算评分者间一致性，以降低个体判断对结果的影响。

第三，模型参数不完全对齐。Midjourney V8.2 采用 RAW 模式、风格化 100、HD，Seedream 5.0 Pro 与 Kling Image 3.0 采用 2K 默认输出。不同平台的生成策略差异无法完全消除，尤其 Midjourney V8.2 的风格化参数可能使其美学表现接近能力上限。但通用能力和准确度维度受风格化影响较小，主要结论仍有效。

第四，提示词约束密度不一致。为接近真实使用场景，提示词约束密度并不完全统一。部分题目信息密度高，部分题目较为开放。提示词越详细，模型越容易被准确执行；提示词越开放，准确度分数可能越低。对于准确度评分为 0 的题目，已尽量复核是否由提示词信息不足导致，但这一因素仍可能对结果产生轻微影响。

第五，只评测「最优一张」，未覆盖生成稳定性。本次评测采用「生成多张、选最优一张」的策略，反映的是模型能力上限，而非生成稳定性。如果模型在多次生成中波动较大，其真实用户体验可能低于本次评测结果。后续应增加多张平均评分或稳定性指标。

第六，版本时效性。文生图模型迭代快速，本次结论仅针对评测时的模型版本。模型更新后，部分结论可能不再成立。

第七，模型生成数量不对等。Midjourney V8.2 网页版批量生成仅提供 1/2/4 张档位，无 3 张选项；为与 Seedream 5.0 Pro、Kling Image 3.0 的 3 张尽量对齐，本次选择 4 张档。最优一张的选择基数因此不对等（4 选 1 vs 3 选 1），理论上可能轻微抬高 Midjourney V8.2 的美学表现。

7.3 结论适用边界与使用建议

为避免本报告结论被过度推广，在此明确说明适用边界与角色化使用方式。

7.3.1 适用边界

本报告结论存在以下边界，超出范围可能产生偏差：

  • 场景边界：仅覆盖风景美学、叙事感女性人像两类场景，不代表产品摄影、工业设计、多人场景、文字渲染等其他场景的表现；
  • 能力边界：仅评测图像的指令准确度与美学质量，不代表视频生成、3D 生成、实时渲染等其他能力；
  • 版本边界：结论仅对应评测时的模型版本，模型迭代后结论可能失效。

7.3.2 分角色使用指南

  • 模型算法团队：重点阅读第四、五章的 Bad Case 归因与错误模式矩阵，定位具体能力短板；
  • 产品选型团队：重点参考 6.1 能力画像，结合业务场景匹配模型。

7.4 下一版改进方向

基于本次评测的经验与不足，后续可以从以下方向继续完善。

  1. 引入多人盲评与一致性检验。邀请不同背景的评分者独立评分，计算评分者间一致性，提升美学质量评分结果的客观性和可信度。
  2. 扩充题库，降低天花板效应。增加高难度、多干扰项的题目，尤其在景别、光效、风格准确度等维度上设计更具区分度的样本，避免区分度不足。
  3. 引入题目难度权重。将 L1、L2、L3 或不同专项的难度差异纳入均分计算，对高难度题赋予更高权重，以更准确反映模型在压力场景下的表现。
  4. 增加生成稳定性评测。在「最优一张」之外，增加多张平均分、方差或可用率等指标，从「能力上限」和「稳定性」两个维度同时评估模型。
  5. 增加中英文对照测试。当前采用各模型最适语言策略，测的是各模型在自身最优语言环境下的能力上限。后续可增加中英文对照测试，评估语言切换对模型表现的影响。
  6. 引入客观指标辅助。在主观评分之外，可引入美学评分模型、清晰度、噪声、构图分析等客观指标，作为主观评分的补充和交叉验证。
  7. 跨版本追踪。对同一题库进行跨版本测试，观察模型能力演进趋势，为模型迭代提供持续反馈。
