# 文生图模型能力评测 · Text-to-Image Model Evaluation

独立完成的三模型文生图系统评测：以 **Midjourney V8.2 / Seedream 5.0 Pro / Kling Image 3.0** 为对象，
通过 **82 道跨场景题目、249 张进入评分的生成图（全量 830 张）**，
覆盖**风景美学**与**叙事感女性人像美学**两个正式评测专项，以及一项通用能力先导研究（方法论验证）。

## 在线浏览

**https://yeyouxu.github.io/ai-vision-eval/**

## 核心结论

| 模型 | 画像 |
|---|---|
| Seedream 5.0 Pro | 指令遵循与准确度最强，均衡可靠 |
| Midjourney V8.2 | 美学质感上限最高，指令执行波动大 |
| Kling Image 3.0 | 整体落后一代，人像皮肤与动态细节差距明显 |

共性短板：文化符号的表面化理解、叙事连贯性缺失、专业风格契合度不足。

## 评测方法速览

- **分层题库**：原子能力 → 组合能力 → 综合压力三层递进
- **双轨评分**：准确度（Prompt 明确涉及，百分制）+ 美学质量（隐性审美，1—5 分锚定制）
- **可追溯**：每题每维度有评分锚点、扣分说明与 Bad Case 归因
- **边界声明**：报告第 7 章完整列出方法局限、结论适用范围与下一版改进方向
